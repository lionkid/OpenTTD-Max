## 1. 比例校正（對照 OpenGFX 原版 sprite）

用 grfcodec 解出 OpenGFX 基底圖組，逐視角量測原版車輛（`tools/calibrate.py`）。得到三個關鍵事實：

| 發現 | 數據（1x） | 處理方式 |
|---|---|---|
| 原版飛機接近真實比例 | 747 級 sprite：E 視角長 68 px、N 視角翼展 66 px，約 1.0 px/m | 飛機統一 1.0 px/m，不做變形 |
| 原版列車「粗壯」 | 車廂 N 視角寬 8 px、E 視角高 12 px，截面約 2.3 px/m；8/8 車廂在 NE 視角只占 16 px | 截面 2.3 px/m，車長壓縮到遊戲長度（25 m 車廂壓成截面比例的 0.39 倍） |
| 斜向軌道上車輛要更長 | OpenTTD 在對角軌道每步同時移動 x、y 各 1 單位，N/E/S/W 視角 8/8 車廂寬 32 px | 偶數視角沿車長再拉長 √2，否則車廂間出現縫隙 |
| 錨點不置中 | 列車 NE/SW 內容起點 x = −14、SE/NW 起點 x = −6；飛機以外框置中 | 列車逐視角水平位移（N/S +1、NE/SW −3、SE/NW +3）；飛機逐視角外框置中 |

校正後的對照結果：

| 車輛 | 對照的原版 sprite | 寬度比 | 高度比 |
|---|---|---|---|
| Boeing 747-400 | 3749（巨無霸級） | 1.04 | 1.01 |
| N700 中間車 | 2953（客車廂） | 1.16 | 1.05 |
| N700 頭車 | 2985（流線型磁浮） | 1.05 | 0.90 |

列車寬度比 1.16 中約 2 px 是對齊用的透明邊，實際內容與原版相差在 10% 以內。所有常數集中在 `tools/ottd_scale.py`。

## 2. 參數化模型產生器

M0 的積木式代理模型全部移除，改成兩個產生器，每款車只需一份參數檔（真實尺寸，公尺）：

| 產生器 | 檔案 | 能力 |
|---|---|---|
| 客機 | `models/lib/airliner.py` | 斷面放樣機身（機鼻、尾錐上翹、747 駝峰、A380 全雙層）、後掠翼含後緣轉折與斜削翼尖、任意平面形（協和號 S 形三角翼）、小翼 / 分叉小翼 / 翼尖小翼 / 翼尖籬、尾翼、渦扇或箱型短艙與派龍、起落架、窗帶 / 駕駛艙 / 公司色帶 |
| 鐵道車輛 | `models/lib/railcar.py` | 超橢圓斷面車身、以控制點定義的車頭外形（頂線、底線、寬度）、逐窗、駕駛艙玻璃、頭燈、塗裝色帶、轉向架、貫通道、集電弓、磁浮底盤 |
| 共用 | `models/lib/geom.py` | 材質、單調三次插值、依弧長均勻取樣的斷面、NACA 翼型、放樣 / 旋轉體 |

同家族共用模組（`models/aircraft/_b747.py`），747-8F 只是在 747-400 的參數上加前後延伸段、縮短上層、換成斜削翼尖並拿掉客艙窗。

| 類別 | 車輛 |

## 4. 其他修正

| 項目 | 問題 | 修正 |
|---|---|---|
| 公司色亮度 | 不同材質與光照下，公司色區平均亮度偏離 OpenTTD 的中性值 128 | 後製逐部件把 CC1 / CC2 區域縮放到平均 128（保留明暗），係數記在 manifest |
| 貨機容量 | 飛機非客運貨物的容量原本靠倍率推算，與酬載噸數無關 | `passenger_capacity` callback 依 `cargo_unit_weight` 換算：容量 = 酬載噸數 ÷ 單位重量 |
| 變體分組 | `VEHICLE_FLAG_SYNC_VARIANT_RELIABILITY` 讓子型號沿用父項目年齡，1998 年的 737-800 在 2012 年就退役 | 移除該旗標，variant_group 只做購買清單分組 |
| 最短可購期 | 部分機型生產期極短（協和號 3 年） | 遊戲內最少 8 年可購（`MIN_MODEL_LIFE`），CSV 保留真實數值 |
| 斷面取樣 | 高指數超橢圓按角度取樣時側面幾乎沒有頂點，色帶畫不出來 | 改為依弧長均勻取樣 |

## 5. 資料查證

`data/aircraft.csv` 49 筆、`data/trains.csv` 31 筆（P0 + P1 + P2）全部經過網路來源查證，套用 41 項修正：

- **飛機（25 筆）**：數個機型改用兩艙等座位（707、727、737-200、747-100、747-400）；多數停產年限改為各變體實際值；A300B4、A320-200、737-900ER、777-9（2027-07）、A350F（2027-12）的投入日期；A330-900 改用官方名稱。
- **列車（16 筆）**：E2 投入日改為東北新幹線 1997-03-22；500 系 8 輛 V 編成日期與座位；N700 8 輛編成無車體傾斜；E8 功率 6,000 kW；Transrapid 09、Linimo、北京 S1、L0 的座位數與重量。
- **刻意保留**：L0 遊戲日期維持原規劃的 2027 年（實際通車仍未定，最早約 2034–2036 年）；三艙等數據的廣體機（A340、A380、747-8I）暫不換算。

## 7. 已知問題與下一步

1. **P1 / P2 圖像**：63 款仍是佔位圖。產生器已就緒，每款只需一份參數檔；737、747、A320、A330 / A340、777、787 家族可大量共用模組。
2. **0 系集電弓**：目前每節中間車都有集電弓，實車是隔節配置；需要第三種部件（有 / 無集電弓）與編組位置判斷。
3. **協和號可購期**：遊戲內 1976–1984 年可購（真實生產 3 年加上最短 8 年規則），之後玩家買不到；是否延長屬於平衡決策。
4. **測試 AI 截圖時機**：高速列車位置回報有 1–2 秒延遲，部分截圖會錯過列車；可改為截圖前暫停遊戲。
5. **OpenTTD 13 / 14**：`make test-grf` 的無 badges 版本仍會編譯（CI 執行），本輪未在 13.4 重新實機測試。
6. **光照**：太陽方向沿用 M0 初值，與 OpenGFX 建築受光面目視一致，尚未做數值比對。

M2（MVP）的內容目標「P0 共 12 款」已在本階段完成，M2 剩下的是發布第一個 alpha（打 tag 讓 CI 產生 GitHub Release）。
