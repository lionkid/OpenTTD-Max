## 4. GRF 參數

| 套件 | 參數 | 預設 | 驗證（2050 年開局，參數關 / 開） |
|---|---|---|---|
| `max-air.grf` | 停用原版飛機 | 關 | 原版飛機 9 款 → 0 款，本套件 15 款不變 |
| `max-rail.grf` | 停用原版磁浮機車（引擎 84–88） | 關 | 原版磁浮機車 4 款 → 0 款，本套件磁浮 7 款不變；磁浮軌道仍由 Transrapid SMT（2004）引入 |

說明文字有英文、繁體中文、日文三種。企劃書 §6.3 其餘參數的處理：「新幹線預設編組」已由變體分組取代；「速度模式」「塗裝模式」「航程限制」留到 M4 平衡階段再決定是否需要。

## 5. 已知問題與下一步（M4）

1. **平衡**：成本、營運成本、容量只做了相對設定（737-800 = 100），尚未跑完整一局檢查各年代的選擇是否合理。
2. **協和號可購期**：仍是 1976–1984 年（真實生產 3 年加上最短 8 年規則），是否延長待決定。
3. **細節程度**：程序化模型重現的是外形輪廓與塗裝分區；艙門、標誌等細節刻意不做（也避開商標）。
4. **公開發布**：M2 的 alpha（打 tag 由 CI 產生 GitHub Release）與 BaNaNaS 上架都屬於對外發布，等決定後再進行。
5. **截圖時機**：高空飛行中的飛機在 4x 畫面外，截圖會是空白；不影響驗證。
