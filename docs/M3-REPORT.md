## 2. 產生器擴充

| 項目 | 用途 |
|---|---|
| 低涵道短艙 `lowbypass` | 707 的 JT3D、727 與 737-200 的 JT8D 細長短艙 |
| 扁平短艙 `flat` | 737 Classic 的 CFM56-3「倉鼠頰」短艙 |
| 機身短掛架 `pylon: "fuselage"` | 727 機尾兩側引擎 |
| 翼尖上翹 `dz` | 787、A350 的機翼撓曲與上翹翼尖 |
| 額外部件 `extra` | BelugaXL 的 8.8 m 貨艙上鼓與水平尾翼端小垂尾 |
| 車廂長度單位 | 由 `car_length_m` 換算（25 m = 8/8）：迷你新幹線 20 m = 6/8、Linimo 13.5 m = 4/8、北京 S1 15 m = 5/8；模型與資料不一致時建置直接失敗 |
| 集電弓隔節 | 新增 `mid_p` 部件，中間車依位置奇偶交替有 / 無集電弓（0、100、200、300、400、500、700、E1、E4、Doctor Yellow） |
| 家族模組 | `_b737`、`_b747`、`_b757`、`_b767`、`_b777`、`_b787`、`_a300`、`_a320`、`_a330`、`_a350`：每個型號的參數檔只有一行呼叫 |
