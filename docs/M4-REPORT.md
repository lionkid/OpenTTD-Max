## 1. 平衡

先在 OpenTTD 15.3 開「車輛永不過期、2051 年」的局，讓原版與本套件全部車種同時可購，由測試 AI 讀出實際價格與營運成本。M3 的手填成本與原版差距很大：

| 指標 | 原版噴射機 | M3 本套件 | M4 本套件 |
|---|---|---|---|
| 每座位價格 | £120–350 | £750–900 | £200–290 |
| 每座位年營運成本 | £17–40 | 約 £10 | £11–24 |
| 超音速機價格 | £153,808（Yate Haugan） | £369,140 | £114,845 |
| 16 節新幹線年營運成本 | 原版電力機車約 £3,400 | £1,096 | £3,232 |

做法改為公式化（`tools/balance.py`）：

- **飛機**：價格 = 520 × 座位^0.85 × 年代係數；營運成本 = (900 + 11.5 × 座位) × 燃油效率（新機型較省）。超音速 ×4.5 / ×2.5。貨機每噸酬載算 3.2 座。
- **列車**：價格 = 95 × 座位 × √(速度 / 250) × 年代係數；營運成本 = 1,200 + 1.4 × 座位 × √(速度 / 250)。磁浮最高 ×1.6，隨速度遞增（Linimo 等低速磁浮幾乎不加價）。
- CSV 的 `cost_factor` / `running_cost_factor` 改為選填的 `price_adj` / `running_adj` 微調倍率。
- 遊戲內實測 80 款車與平衡表的誤差全部在 0.09% 以內。
- L0 與 CRRC 600 的營運成本觸及屬性上限（£3,583 / 年），`tools/validate.py` 會提示。

完整對照表：`docs/BALANCE.md`。

## 2. 生命週期

OpenTTD 會在 `model_life` 之後再保留 10–20 年的衰退期，導致車輛比實際生產多賣約 10 年（707 生產 1962–1978，遊戲中賣到 1993）。改為所有會過期的車加上 `retire_early: -8`，衰退期一開始就停售。協和號另以 `game_model_life` 對應 1976–2003 服役期。

| 車種 | 真實 | 遊戲內可購（修正後） |
|---|---|---|
| 協和號 | 服役 1976–2003 | 1978–2004 |
| Boeing 707-320B | 生產 1962–1978 | 1964–1981 |
| Boeing 737-800 | 生產 1998–2020 | 2001–2024 |
| Boeing 747-400 | 客機生產 1989–2005 | 1992–2008 |

## 3. 完整一局測試（1950–2050）

測試 AI 新增「時間軸模式」（不貸款、不建造、每年 1 月記錄可購車種），QA 腳本新增無上限快轉與「跑到指定年份」。100 年在空地圖上約 2–3 分鐘跑完。

- 101 個年份全部記錄，無當機、無 NewGRF 錯誤或警告。
- 每款車都在真實投入日期後 3.5 年內上市（OpenTTD 隨機延後 0–1.4 年再加 1 年獨家試用期），上市後無中斷。
- 1964 年起每年至少有一款本套件飛機，1967 年起每年至少有一款列車。

報告與時間軸圖：`docs/TIMELINE.md`、`docs/qa/timeline.png`。

## 5. 未完成與原因

1. **推送 tag**：`v0.1.0-alpha` 已在本地建立（指向 e6b0249），但雲端 session 的 git 通道拒絕推送 tag（HTTP 403）。需要作者在自己的電腦推送，指令在 `docs/RELEASE.md`。
2. **BaNaNaS 上架**：需要作者以 GitHub 帳號登入 BaNaNaS 上傳。另外開發環境連不到 BaNaNaS API，GRF ID `MAX\01`、`MAX\02` 是否已被他人使用尚未確認，上傳時若被拒需改 ID。
3. **人工試玩**：自動測試涵蓋了數值、時間軸與穩定性，但「好不好玩」仍建議實際玩一局確認。
